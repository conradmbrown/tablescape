# Historical tabletop prototype

`Source/`, `Config/`, `ScapeTabletop.uproject`, older exporter integrations and legacy service templates belong to an earlier **TableScape** Unreal/OS1 experiment. They are retained as project history, not as another supported gameplay client.

Current gameplay uses LostCityRS revision 274 through Unity or the native visionOS client. Start with [README.md](README.md); do not launch the legacy viewer or services as a substitute.

The optional historical Unreal build requires an operator-configured `SCAPE_UNREAL_ENGINE` installation directory and the same mounted-storage configuration as other build scripts. Runtime/vendor installations, exports, deployment details and machine-specific service configuration are not included. Service files under `service/units/` are templates only.
